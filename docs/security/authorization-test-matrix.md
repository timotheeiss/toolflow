# Authorization negative-test matrix

Date: 2026-08-10  
Scope: Toolflow MVP trust boundaries

Every authorization decision is deny-by-default. This matrix maps each decision family to executable negative evidence; the pilot security review reruns the environment-dependent rows against provisioned services.

| Boundary                          | Negative cases                                                                                                                                        | Executable evidence                                                                                                     |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Session and bearer authentication | Missing authentication, missing organization claim, invalid role, inactive membership, exact Bearer parsing                                           | `packages/auth/src/auth.test.ts`, `packages/auth/src/session-authenticator.test.ts`, `apps/control-api/src/app.test.ts` |
| Organization roles                | Every declared permission across admin, builder, and member; builder user-management denial                                                           | Exhaustive table in `packages/policy/src/policy.test.ts`                                                                |
| Control API                       | Builder denial on every admin mutation/read; member denial on every administration read; builder denial for non-owned app detail, activity, and audit | Parameterized endpoint matrix in `apps/control-api/src/app.test.ts`                                                     |
| Organization tenancy              | An authenticated principal selecting another organization cannot resolve an existing app or receive its identifier                                    | Live case in `apps/mcp/src/protocol.integration.test.ts`                                                                |
| App/source tenancy                | An existing source version from app A cannot be read through existing app B                                                                           | Live case in `apps/mcp/src/protocol.integration.test.ts`                                                                |
| App membership                    | Non-member receives generic not found; grant takes effect; revoke takes effect on the next request                                                    | Live cases in `apps/mcp/src/protocol.integration.test.ts`                                                               |
| Preview/production isolation      | Records written in preview are absent in production and production records are absent in preview                                                      | Live cases in `apps/mcp/src/protocol.integration.test.ts`                                                               |
| Runtime route authorization       | Denied/malformed authorization, suffix-confusion hostname, and a valid grant for another route all fail before rate limiting or user-code dispatch    | `apps/runtime-dispatch-worker/src/index.test.ts`                                                                        |
| Runtime private services          | Missing/wrong narrow service credential and missing user authentication are denied                                                                    | `apps/runtime-dispatcher/src/app.test.ts`                                                                               |
| Runtime data context              | Missing/invalid signed contexts are denied; live revoked-member and environment isolation cases cover signed-context access                           | `apps/data-gateway/src/app.test.ts`, `apps/mcp/src/protocol.integration.test.ts`                                        |
| SQL capabilities                  | Multiple statements, undeclared relations, system catalogs, disallowed functions, and parameter mismatches are rejected                               | `packages/data-policy/src/sql-policy.test.ts`                                                                           |
| Egress capabilities               | Prefix-confusion hosts and redirects are denied without credential leakage                                                                            | `apps/runtime-outbound/src/index.test.ts`                                                                               |
| Production deployment             | Non-owners, missing exact previews, inactive/unapproved catalog capabilities, destructive schemas, and invalid rollback targets are denied            | `apps/mcp/src/protocol.integration.test.ts`, `packages/policy/src/policy.test.ts`                                       |
| Secret tenancy                    | Cross-organization secret lookup and KMS-context mismatch are rejected; tampering fails authenticated decryption                                      | `packages/secrets/src/vault.test.ts`                                                                                    |
| Audit integrity                   | Updates/deletes are rejected at the database boundary                                                                                                 | `packages/database/src/migration.integration.test.ts`                                                                   |

The authoritative local commands are `pnpm check`, the database integration suite, and the live MCP integration suite. Provider routing, identity, and edge bindings must additionally be exercised during the independent pilot-scope security review.
